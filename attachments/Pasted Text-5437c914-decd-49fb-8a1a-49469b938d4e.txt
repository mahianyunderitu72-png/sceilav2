BUOY
I want to clone openrouter. Not exactly, but the idea of aggregating AI providers and have one unified API and billing. The context is, a platform to allow people with no code skills to create simple AI agents in about five steps. 
Step 1. Select a template. Each template presents a code block, and depending on the task the agent is to perform.
Step 2. Select tools. Tools are what gives agents abilities to act. Examples of tools includes RAG, mcp, telegram, calendar, email, etc
Step 3. Select/create skills. Skills are instructions or context for agents to follow. Example is a humanizing skills, a coding skill, a presentation skill, etc
Step 4. Select models. Model are LLMs that the agent will use. Users select all model that are required and preferably more than one so that when one hit API call limit, the other is used
Step 5. Create the agent. An agent made of the template codeblock, tools, skills, model is used. We call this agent a buoy.

At step 4, if where inspiration from open router comes from.
